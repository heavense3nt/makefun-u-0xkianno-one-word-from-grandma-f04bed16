"witchcraft" — the single word Grandma would text about AI.

## Why this word

Ask a grandma what she thinks of AI and she won't give you a lecture. She'll
give you one word, typed with one finger, warm and a little baffled: it's
witchcraft. It lands without a caption, it could only be about the machine
that talks back, and no grandma in the world would text "blockchain".

## How it works

`main.ts` writes exactly one word — `witchcraft`, 10 bytes, no trailing
newline — to `entry.txt` in the output directory. The output directory comes
from `MAKEFUN_OUTPUT_DIR` (absolute paths are used as-is, relative ones are
resolved against the repository root), so the program behaves identically
locally and in the grader sandbox.
